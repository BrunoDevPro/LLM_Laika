# Laika

Um modelo de linguagem pequeno, em português, treinado do zero. Conversa, resume textos e busca informações na
Wikipédia, e roda no próprio celular (app Android).

[![Abrir no Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/BrunoDevPro/LLM_Laika/blob/main/colab.ipynb)

O nome é uma homenagem à cadela Laika, que foi ao espaço no Sputnik 2, em 1957.
